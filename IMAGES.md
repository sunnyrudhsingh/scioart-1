# Images

SciOArt is designed to look complete before a single photo is added: every crop has its own drawn illustration on a season-coloured background, and the home page uses an original drawing of a Punjab farm at sunrise. Photos make it real. This file lists every photo the site can use today.

## How photos work

Put a file at the exact path listed below and redeploy. The site checks for the file during the build: if it exists, the photo is shown (resized and compressed automatically, with a soft placeholder while it loads); if not, the illustration stays. Nothing else needs to change.

## Rules for every photo

- **Format:** JPG (photos) or PNG (only for graphics with flat colours). Lowercase file names, exactly as listed.
- **Size:** at least 1600 px on the long side; landscape 16:10 or 5:4 crops well everywhere.
- **Weight:** under **300 KB**. Export at JPG quality 70–80 or run the file through squoosh.app.
- **Content:** real Punjab fields, farmers and PAU work. Sharp, natural light, no text on the image, no watermarks, no logos or brand names of products (especially pesticides).
- **People:** get the person's permission. For children, get a parent's permission.
- **Rights:** use photos taken by PAU or the SciOArt team, or with written permission. Record the photographer for each file in the credits table below.

## Folders ready for later

These folders exist so material has an agreed home. The pages currently use illustrations here; wiring a photo into one of these places is a small code change.

| Folder                      | For                                                                                         |
| --------------------------- | ------------------------------------------------------------------------------------------- |
| `public/images/hero/`       | A photographic alternative to the home illustration (2400 × 1350, subject low in the frame) |
| `public/images/operations/` | One photo per operation, e.g. `seed-sowing.jpg` (sowing with a happy seeder)                |
| `public/images/topics/`     | One photo per topic, e.g. `residue-management.jpg`                                          |
| `public/images/learn/`      | Covers for songs, videos, stories (1600 × 900)                                              |
| `public/images/kits/`       | Photos of kit sessions in villages (1600 × 1000)                                            |
| `public/images/advisories/` | Photos for advisories (e.g. a pest close-up)                                                |
| `public/images/stories/`    | Portraits of farmers in farmer stories                                                      |
| `public/images/about/`      | Team and PAU campus photos for the About page                                               |
